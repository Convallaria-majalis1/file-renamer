# 批量重命名 / 归档器

> 把几百个乱名字的文件按规则一次性改整齐；把散落各处的照片、合同、扫描件按年月自动归位。
> 改之前能预览，改错了能一键撤销，**不删任何文件**。

**[⬇ 下载 FileRenamer v1.0.0（Windows，免安装）](https://github.com/Camellius-lan/file-renamer/releases/download/v1.0.0/FileRenamer_v1.0.zip)**

> 下载后解压，双击 `FileRenamer.exe` 即可。不需要装 Python，不联网，文件不会离开你的电脑。



---

## 它解决什么问题


| 场景                                                                          | 手工的痛苦                                 |
| ----------------------------------------------------------------------------- | ------------------------------------------ |
| 手机导出的几百张照片（`IMG_0001.JPG`、`IMG 0002.JPG`，带空格带括号）          | 一张张改，改到眼花，还容易重名             |
| 客户陆续发来的合同（`合同.docx`、`合同 副本 (1).docx`、`合同 副本 (2).docx`） | 名字全一样，找不到哪份是最新的             |
| 扫描仪导出（`scan001.PDF` ~ `scan500.PDF`）                                   | 看不出是哪个月的，越堆越乱                 |
| 年底整理资料                                                                  | 一年下来十几个文件夹，按月份归档得拖一下午 |

这个工具把这些事压成三步：**选文件夹 → 预览 → 执行**。

---

## 三个让它敢用的设计

1. **先预览，后执行**。改之前能看到"原名 → 新名"对照表，规则不满意随时调，文件一个都不会动。
2. **重名不覆盖**。目标名已存在时自动加 ` (2)`、` (3)`，不会把原文件顶掉。
3. **一键撤销**。每次真实操作都会在程序目录的 `操作记录/` 写一份记录，点"撤销上一批操作"能全部还原。

第 3 条是最值钱的：批量操作的真正风险不是改错，是"改错了回不去"。能撤销，人才敢点那个按钮。

## 功能

**批量重命名**（规则按顺序依次套用）


| 顺序 | 规则                     | 例子                                          |
| ---- | ------------------------ | --------------------------------------------- |
| 1    | 查找替换（可勾"用正则"） | `副本` → 空，`合同 副本 (1)` 变成 `合同 (1)` |
| 2    | 大小写转换               | `IMG` → `img`                                |
| 3    | 整理多余空格             | ` IMG 0001 .JPG` 压成 `IMG 0001.JPG`          |
| 4    | 加日期前缀               | `20260803_`（取文件修改时间）                 |
| 5    | 加前缀 / 后缀            | `资料_` + 原名                                |
| 6    | 加序号                   | `_001`、`_002`（起始、位数、步长可调）        |

扩展名始终保留在末尾，不会被规则改掉。

**批量归档**（五种方式）


| 方式           | 归到哪                                            | 适合           |
| -------------- | ------------------------------------------------- | -------------- |
| 按年份         | `2026/`                                           | 年度资料盘     |
| 按年/月        | `2026/2026-11/`                                   | 最常用         |
| 按年/月/日     | `2026/2026-11/2026-11-25/`                        | 每日照片、流水 |
| 按文件类型     | `图片/` `文档/` `视频/` `音频/` `压缩包/` `其他/` | 混杂文件初筛   |
| 按年/月 + 类型 | `2026/2026-11/文档/`                              | 既按月又分类   |

- 日期取的是文件**修改时间**，和资源管理器里看到的一致
- 勾"包含子文件夹"时**保留原有目录层级**，不会拍平，同名文件不打架
- 目标默认是 `源文件夹/已归档`，程序会自动跳过这个目录，不会二次归档
- 可勾"只复制不移动"，先看效果再真动（复制模式不写撤销记录）

## 系统要求

- Windows 10 / 11（64 位）
- 免安装版：什么都不用装
- 从源码运行：Python 3.9+，**不需要任何第三方包**（只用标准库 tkinter / pathlib / shutil / re）

---

## 从源码运行

```bat
python main.py
```

或双击 `运行.bat`。用 `示例文件/` 里的 10 个故意弄乱的文件练手：

1. 重命名页 → 文件夹选 `示例文件`
2. 前缀填 `资料_`，勾上"加序号"和"加日期前缀"
3. 点"预览改名结果"，看对照表
4. 点"执行重命名"
5. 想反悔点"撤销上一批操作"

预览应看到：` IMG 0001 .JPG` → `资料_20260803_IMG 0001_001.JPG`，10 个文件全部"正常"。

命令行也能跑：

```bat
python core.py rename 示例文件 --prefix 资料_ --seq --date
python core.py archive 示例文件 --dest 归档 --mode month
python core.py undo
```

## 不做的事


| 能做                                         | 不做                                       |
| -------------------------------------------- | ------------------------------------------ |
| 批量改名（前缀后缀、替换、正则、序号、日期） | 改文件内容                                 |
| 按日期/类型归档，保留子目录结构              | 按文件内容识别分类（如识别照片里有没有人） |
| 冲突自动加序号，不覆盖                       | **删除文件**（本工具只改名和移动）         |
| 一键撤销上一批                               | 跨磁盘移动大文件的进度显示                 |

**这个工具不删文件。** 数据全部在本机处理，不联网、不上传。

## 常见问题


| 现象                | 原因                                   | 解决                                  |
| ------------------- | -------------------------------------- | ------------------------------------- |
| 预览里全是"未变化"  | 规则没生效（只填了"替换为"没填"查找"） | 检查规则，或加个前缀试试              |
| 显示"规则错误"      | 正则写错了                             | 取消"用正则"，先用普通替换            |
| 改名后顺序乱了      | 排序按目录 + 文件名                    | 用"加序号"重新编号                    |
| 撤销提示"跳过 N 个" | 原位置已有同名文件，或文件被挪走       | 保护机制，手动处理这几个              |
| 归档后文件不见了    | 去了目标文件夹                         | 看日志里的路径                        |
| exe 被安全软件报毒  | PyInstaller 单文件打包的常见误报       | 加信任，或`python main.py` 从源码运行 |
