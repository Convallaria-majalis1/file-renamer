# 批量重命名 / 归档器 v1.0

> 把几百个乱名字的文件，按规则一次性改整齐；把散落各处的照片、合同、扫描件，按年月自动归到对应文件夹。
> 双击运行，改之前能预览，改错了能撤销。

---

## 一、它解决什么问题

| 场景 | 手工的痛苦 |
|---|---|
| 手机导出的几百张照片（`IMG_0001.JPG`、`IMG 0002.JPG`、带空格带括号） | 一张张改，改到眼花，还容易重名 |
| 客户陆续发来的合同（`合同.docx`、`合同 副本 (1).docx`、`合同 副本 (2).docx`） | 名字全一样，找不到哪份是最新的 |
| 扫描仪导出（`scan001.PDF` ~ `scan500.PDF`） | 看不出是哪个月的，越堆越乱 |
| 年底整理资料 | 一年下来十几个文件夹，想按月份归档得拖一下午 |

这个工具把这些事压缩成三步：**选文件夹 → 预览 → 执行**。

---

## 二、三个让客户敢用的设计（这是你卖点）

1. **先预览，后执行**。改之前能看到"原名 → 新名"对照表，不满意的规则随时改，文件一个都不会动。
2. **重名不覆盖**。目标名已存在时自动加 ` (2)`、` (3)`，不会把你原来的文件顶掉。
3. **一键撤销**。每次真实操作都会在程序目录的 `操作记录/` 里写一份记录，点"撤销上一批操作"就能全部还原。

第 3 条是最值钱的：客户最怕的就是"批量操作把文件搞乱了"。有撤销，他才敢点那个按钮。

---

## 三、快速开始

```bat
python main.py
```

或者直接双击 `运行.bat`。

用 `示例文件/` 里的 10 个文件练手：

1. 重命名页 → 文件夹选 `示例文件`
2. 前缀填 `资料_`，勾上"加序号"和"加日期前缀"
3. 点"预览改名结果"，看对照表
4. 点"执行重命名"
5. 想反悔就点右下角"撤销上一批操作"

**预览应该看到**：` IMG 0001 .JPG` → `资料_20260803_IMG 0001_001.JPG`，10 个文件全部"正常"。

> 本作品只用 Python 标准库，不需要 `pip install` 任何包，也不用装 pandas。

---

## 四、重命名：规则的执行顺序

规则按下面顺序依次套用，顺序会影响结果，这点要跟客户讲清楚：

| 顺序 | 规则 | 例子 |
|---|---|---|
| 1 | 查找替换（可勾"用正则"） | `副本` → 空，`合同 副本 (1)` 变成 `合同 (1)` |
| 2 | 大小写转换 | `IMG` → `img` |
| 3 | 整理多余空格 | ` IMG 0001 .JPG` 里的多余空格压成一个 |
| 4 | 加日期前缀 | `20260803_`（取文件修改时间） |
| 5 | 加前缀 / 后缀 | `资料_` + 原名 |
| 6 | 加序号 | 末尾加 `_001`、`_002`（位数、起始、步长可调） |

扩展名始终保留在后面，不会被规则改掉。

**常用的三套配置：**

- 照片整理：加日期前缀（`%Y%m%d`）+ 加序号（3 位）
- 合同归档：前缀 `合同_` + 查找替换去掉"副本" + 加序号（2 位）
- 扫描件统一：查找 `scan` 替换为 `扫描件_` + 加序号（4 位）

## 五、归档：五种方式

| 方式 | 归到哪 | 适合 |
|---|---|---|
| 按年份 | `2026/` | 年度资料盘 |
| 按年/月 | `2026/2026-11/` | 最常用，月度资料 |
| 按年/月/日 | `2026/2026-11/2026-11-25/` | 每日照片、流水 |
| 按文件类型 | `图片/` `文档/` `视频/` `音频/` `压缩包/` `其他/` | 一堆混杂文件的初筛 |
| 按年/月 + 类型 | `2026/2026-11/文档/` | 既要按月又要分类 |

三个细节：

- 日期取的是文件的**修改时间**（不是创建时间），跟资源管理器里看到的一致。
- 勾了"包含子文件夹"时，**保留原有的目录层级**，不会把所有文件拍平，避免不同文件夹的同名文件打架。
- 目标文件夹默认是 `源文件夹/已归档`，程序会自动跳过这个目录，不会把归档好的文件又归一遍。

**"只复制不移动"** 这个勾选项是给第一次用的客户准备的：先复制一份看看效果，确认没问题再真正移动。注意复制模式不写撤销记录。

## 七、能力边界

| 能做 | 不做 |
|---|---|
| 批量改名（前缀后缀、替换、正则、序号、日期） | 改文件内容 |
| 按日期/类型归档，保留子目录结构 | 按文件内容识别分类（比如识别照片里有没有人） |
| 冲突自动加序号，不覆盖 | 删除文件（本工具只改名和移动，不删） |
| 一键撤销上一批 | 跨磁盘移动大文件时的进度显示 |

最后一条要主动说明：**这个工具不删文件**。客户听到这句，戒心会降一半。

## 八、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 预览里全是"未变化" | 规则没生效（比如只填了替换但没填查找内容） | 检查规则，或加个前缀试试 |
| 有些文件显示"规则错误" | 正则写错了 | 取消"用正则"，先用普通替换 |
| 改名后顺序乱了 | 排序按目录 + 文件名 | 用"加序号"重新编号 |
| 撤销时提示"跳过 N 个" | 原位置已经有同名文件，或文件被手动挪走 | 正常保护机制，手动处理这几个即可 |
| 归档后文件不见了 | 去了目标文件夹 | 看日志里记录的路径 |

```bat
python core.py rename 示例文件 --prefix 资料_ --seq --date
python core.py archive 示例文件 --dest 归档 --mode month
python core.py undo
```
